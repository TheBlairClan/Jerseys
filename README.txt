Kutztown Jersey Numbers Practice (GitHub Pages-friendly)

This version auto-loads roster.csv at page load (so edits to roster.csv take effect after refresh).

Files:
- index.html  (the app)
- roster.csv  (Kutztown women's lacrosse, spring 2027)
- README.txt

GitHub Pages setup:
- Put these files in the ROOT of your repo
- Settings → Pages → Deploy from branch → main / (root)

Updating roster:
- Edit roster.csv in GitHub (or commit changes), then refresh the page.
- If you don't see changes immediately, do a hard refresh (Cmd+Shift+R) or reopen the tab on iPhone.

CSV format:
- Headers must include: Number, Last Name
- Optional: First Name. This enables full names in the Show menu.
